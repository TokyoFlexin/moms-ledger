# Mom's Ledger

A receipt-style expense ledger for tracking what I pay while Mom is overseas and what she has paid back.

Live: https://tokyoflexin.github.io/moms-ledger/

Expenses are saved in the browser on each device (localStorage), never in this repo. Optional sync stores them as `ledger.json` in the private repo `TokyoFlexin/moms-ledger-data`, using a fine-grained token pasted into the page on each device. Open the site with `#selftest` to run the merge self-check (results in the console). Use **Save backup** / **Load backup** to keep a copy or move to another device.
